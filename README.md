# Voxel Survival (Godot 4)

Minecraft-inspired voxel survival prototype built with Godot 4. Includes procedural terrain, block breaking/placing, basic inventory/crafting, survival stats, hostile slimes and JSON world saves.

## Run
1. Install Godot 4.3 or newer.
2. Clone this repository and open `project.godot` in Godot.
3. Press F6/F5 or Play.

Controls: WASD move, Space jump, mouse look, left click mine, right click place, 1-5 select hotbar, E inventory/crafting, F5 save, F9 load, Esc release mouse.

Save file is stored in `user://voxel_world.json`.
